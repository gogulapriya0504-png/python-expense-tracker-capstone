### 📌 Project Description
A simple and smart personal expense tracker built with Python Flask and SQLite. Users can add, view, and delete their daily expenses and track total spending.

### ✨ Features
- Add New Expense (Amount, Category, Note, Date)
- View All Expenses in Table
- Delete Expense
- Auto Calculate Total Expense
- Responsive Design with Bootstrap

### 🛠️ Tech Stack
- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, Bootstrap 5
- **Database:** SQLite3
- **Deployment:** Render
